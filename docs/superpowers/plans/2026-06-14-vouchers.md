# Vouchers (upgrades permanentes) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar 4 Vouchers (upgrades permanentes) comprados na loja (1 slot, $10), que modificam economia/loja/rodada de forma passiva.

**Architecture:** Vouchers são dados passivos em `js/data/vouchers.js`; o jogador os guarda em `state.vouchers` (array de ids). Cada efeito é uma consulta `state.vouchers.includes(id)` no ponto de integração: re-roll inicial (Bússola) e preço de item (Liquidação) em `shop.js`, teto de juros (Juros+) em `economy.js`, mãos por rodada (Mãos+) em `run.js`. A loja ganha 1 slot de voucher (`comprarVoucher`); re-roll não o troca.

**Tech Stack:** JS puro (ES modules, sem build), harness próprio, `node tests/todos.js`.

**Convenções:** código/comentários em PT-BR; zero deps; commit termina com `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.

**Spec:** `docs/superpowers/specs/2026-06-14-vouchers-design.md`

**Backward-compat verificada:** `juros`/`recompensaBlind` ganham parâmetro de teto **com default 5**, então os testes existentes em `tests/economy.test.js` (`juros(0)`, `recompensaBlind("pequena",2,10)`) continuam passando sem mudança. `state.test.js` não checa shape exaustivo — adicionar `vouchers: []` não o quebra.

```js
export function comprarVoucher(state) {
  if (!state.loja.voucher) return { erro: "vazio" };
  if (state.dinheiro < PRECO_VOUCHER) return { erro: "sem-dinheiro" };
  state.dinheiro -= PRECO_VOUCHER;
  state.vouchers.push(state.loja.voucher.id);
  state.loja.voucher = null;
  return {};
}
```

```js
function cartaoVoucher(state) {
  const v = state.loja.voucher;
  if (!v) return el("div", { classe: "slot-vazio" });
  const def = VOUCHERS[v.id];
  const cartao = el("div", { classe: "voucher" }, el("span", { classe: "nome" }, def.nome));
  ligarTooltip(cartao, `<strong>${def.nome}</strong><br>${def.descricao}`);
  return el("div", { classe: "cartao-item" },
    cartao,
    el("button", {
      classe: "botao botao-azul",
      onclick: () => { const r = comprarVoucher(state); if (r.erro) avisar(r.erro); else atualizar(); },
    }, `Comprar $${PRECO_VOUCHER}`),
  );
}

function vouchersPossuidos(state) {
  if (!state.vouchers.length) return el("p", { classe: "descricao" }, "Vouchers: nenhum");
  const nomes = state.vouchers.map((id) => VOUCHERS[id].nome).join(", ");
  return el("p", { classe: "descricao" }, `Vouchers: ${nomes}`);
}
```
